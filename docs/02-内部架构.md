### 2.2 MCP 错误码语义分组（抽样）

| 分组 | 样例 |
|---|---|
| 账号态 | `MCP_ACCOUNT_REQUIRED`、`MCP_ACCOUNT_SUSPENDED` |
| App 资源 | `MCP_APP_RESOURCE_MIME_TYPE_INVALID`、`MCP_APP_RESOURCE_TOO_LARGE`、`MCP_APP_RESOURCE_URI_INVALID`、`MCP_APP_RESOURCE_MISMATCH`、`MCP_APP_RESOURCE_CONTENT_INVALID` |

### 2.5 插件私有协议

内置插件（workspace/git/terminal/agent）不走标准 MCP，而是**自定义长度前缀协议**：

```
[4 字节小端长度][JSON 负载]
```

握手：`{type: "watchRelayClients", protocolVersion: 2}`，超时 5 秒。

已识别方法族（见 `docs/01 §4.3`）分四组：
- `system.*`（hello/ping/health/shutdown）
- `workspace.*`（11 个，含 read/write/watch/snapshot）
- `git.*`（8 个，含 review 系列）
- `terminal.*`（5 个）、`agent.*`（11 个）

## 3. 工作区远程模式

`mode` 字段三态，控制 Agent 与工作区的部署位置：

| mode | agent | workspace | 场景 |
|---|---|---|---|
| 缺省 / `local` | local | local | 本地 |
| `ssh-managed` | remote | remote | 全远端 |
| `ssh-local-agent` | local | remote | **Agent 本地 + 代码远端** |

校验逻辑（`FV()`）极其严格：`host.id`/`host.kind`/`host.label`/`workspace.id`/`workspace.path` 全部必填，`kind∈{local,ssh}`，且`mode` 与 `host.kind` 的组合必须自洽（如 `kind==="ssh"` 且 `mode==="local"` 直接拒绝）。

还支持 git worktree 派生工作区，`source="app"` 时需带 `repositoryId`/`checkoutId`/`sourceRepositoryRoot`/`worktreeRepositoryRoot`。
